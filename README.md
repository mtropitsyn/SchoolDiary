# SchoolDiary

Электронный дневник: классы, ученики, оценки и отчёты по успеваемости.

Стек: PHP, PDO, MS SQL Server / SQLite, HTML, CSS и JavaScript.

## Что умеет

- Администратор добавляет пользователей, классы, учеников и предметы, назначает учителей.
- Учитель видит назначенные классы и ставит оценки по своим предметам.
- Оценки можно изменить или удалить, добавить дату и комментарий.
- По классу рассчитывается средний балл за выбранный период. Отчёт выгружается в CSV.

## Запуск

Нужен PHP 8.3+ с `pdo_sqlite` и `mbstring`. Из корня репозитория:

```bash
cp .env.example .env
```

В `.env` задать пароль администратора в `ADMIN_PASSWORD` (от 10 символов), затем:

```bash
php scripts/init.php
php -S 127.0.0.1:8080 -t public
```

Открыть http://127.0.0.1:8080. Логин по умолчанию — `admin`, пароль — из `.env`.
SQLite создаётся в `var/diary.sqlite`.

Для примера с двумя классами и учителями в новой базе задать также `DEMO_PASSWORD` и выполнить:

```bash
php scripts/init.php --demo
```

Учителя в примере: `teacher1` и `teacher2`. Вход с паролем из `DEMO_PASSWORD`.
Демо добавляется только в базу без классов и не заменяет существующие записи.

[Подключение MS SQL Server](docs/sql-server.md).

## Проверки

```bash
php tests/run.php
python tests/http_test.py
```

Второй набор использует Python 3 и поднимает локальный PHP-сервер с временной базой.
CI проверяет работу с SQLite и MS SQL Server.

## Файлы проекта

- `app/` — подключение к базе, авторизация и работа с дневником.
- `public/` — страницы и оформление; эта папка должна быть корнем сайта.
- `sql/` — схемы для обеих баз.
- `scripts/` — создание базы и демонстрационных записей.
- `tests/` — проверки логики и HTTP-запросов.

Вход выполняется через POST, пароли хранятся в виде хешей. Формы защищены CSRF-токеном.
Старая версия, её документы и бэкапы сохранены в истории. Они не импортируются автоматически в новую схему.
